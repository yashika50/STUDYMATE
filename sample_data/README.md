# Sample Data

StudyMate needs PDF lecture files to work. Since generating PDFs programmatically
adds unnecessary complexity, here's how to quickly get demo material:

## Option 1 — Use the included sample PDFs

Run the helper script to generate small sample PDFs:

```bash
python generate_samples.py
```

This creates three short PDFs in this folder:
- `TQM_Lecture.pdf` — Total Quality Management basics
- `Manufacturing_Processes.pdf` — Overview of casting, machining, and forming
- `Operations_Research.pdf` — Linear programming and optimization fundamentals

## Option 2 — Use your own lecture slides

Export any lecture PowerPoint as PDF (File → Save As → PDF) and upload it into
StudyMate.

## Option 3 — Grab free lecture PDFs from the internet

Search for open-courseware lecture PDFs on topics you study.  MIT OpenCourseWare
(ocw.mit.edu) is a great source.
